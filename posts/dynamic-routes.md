---
title: 'Understanding Dynamic Routes in Next.js'
date: '2026-09-17'
---

A file named `[id].js` can represent many pages. The value in the URL becomes the `id` parameter, which lets one component display different posts.

For this blog, each Markdown filename becomes a possible route. The post named `dynamic-routes.md` can be opened at `/posts/dynamic-routes`.

That keeps the project small: one page component can welcome an entire shelf of posts.
